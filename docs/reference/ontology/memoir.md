# Memoir

Hybrid function based on personal memory with narrative style. Includes (auto)biographies.

## Genre hierarchies

| Classification         | Description                                                            | Examples                                                                   |
|------------------------|------------------------------------------------------------------------|----------------------------------------------------------------------------|
| `Memoir/Autobiography` | First-person factual reconstruction of the author's own life           | *Me Talk Pretty One Day* (David Sedaris), *Angela's Ashes* (Frank McCourt) |
| `Memoir/Biography`     | Third-party factual reconstruction of a person's life                  | *Unbroken* (Laura Hillenbrand), *The Diary of a Young Girl* (Anne Frank)   |
| `Memoir/Personal`      | Subjective account with narrative style, not tied to a specific person | *The Year of Magical Thinking* (Joan Didion)                               |
