# Theatre

Text intended for stage performance (scripts, dramas, libretti). Structured as dialogue and stage directions, not prose.

## Genre hierarchies

| Classification    | Description   | Examples                                                                      |
|-------------------|---------------|-------------------------------------------------------------------------------|
| `Theatre/Comedy`  | Comedic plays | *The Importance of Being Earnest* (Oscar Wilde), *No Exit* (Jean-Paul Sartre) |
| `Theatre/Tragedy` | Tragic plays  | *Hamlet* (William Shakespeare), *Oedipus Rex* (Sophocles)                     |
