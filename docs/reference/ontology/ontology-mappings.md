# Ontology mappings

Maps TomeTrove classifications to OpenLibrary subjects and Google Books categories. Each row is a single TomeTrove classification (with fixed vocabularies inlined). Open vocabularies (shown as `<Country>`, `<Instrument>`, etc.) have no fixed mapping — the value is filled at classification time.

See also: [ontology reference](index.md).

OpenLibrary values are subject slugs, usable as `https://openlibrary.org/subjects/<slug>.json`; multiple slugs joined by `+` mean the intersection of those subjects. Google Books values are BISAC subject headings, the vocabulary Google Books uses for its `categories` field. Headings containing `<Region>`, `<Country>` or similar are resolved against the BISAC list at classification time; where BISAC has no such level the Note column says so.

The table is written for the import direction: given a book, look its subjects up in OpenLibrary first (its subject strings carry the facet — `criticism_and_interpretation`, `history`, `exhibitions`, `dictionaries`, a person's name), then pick the row whose Note tests the subjects match. Google Books/BISAC is the confirming source for the top-level branch and the fallback for recent or non-English titles that OpenLibrary does not cover.

`Monograph` rows carry only the discipline subject on the OpenLibrary side: OpenLibrary has no monograph facet, so the monograph's own subject (a person, work, building, object or movement) is added as a further subject at classification time.
