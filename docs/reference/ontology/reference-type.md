# Reference

Point lookup (encyclopedia, dictionary, yearbook, sacred text). Includes pure inventories and auction catalogues with no analytical content.

## Genre hierarchies

| Classification                    | Description                                                                            | Examples                                                                                                                                       |
|-----------------------------------|----------------------------------------------------------------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------|
| `Reference/Encyclopedia`          | Comprehensive reference works                                                          | *Encyclopaedia Britannica*                                                                                                                     |
| `Reference/Dictionary/<Language>` | Language and specialized dictionaries                                                  | *Oxford English Dictionary*                                                                                                                    |
| `Reference/Yearbook`              | Annual publications with statistics and facts                                          | *The World Almanac and Book of Facts*                                                                                                          |
| `Reference/Atlas`                 | Geographical and thematic atlases                                                      | *National Geographic Atlas of the World*                                                                                                       |
| `Reference/Humor`                 | Joke collections and non-narrative humor compilations                                  | *1,000 Jokes for Kids* (Michael Kilgariff)                                                                                                     |
| `Reference/Catalogue`             | Pure inventories, auction catalogues, and collection listings with no critical content | *Christie's Auction Catalogue* (Christie's)                                                                                                    |
| `Reference/Religion/<Faith>`      | Reference works tied to a specific faith (sacred texts, catechisms, liturgical books)  | *The Bible* → `Reference/Religion/Christianity`, *The Quran* → `Reference/Religion/Islam`, *The Bhagavad Gita* → `Reference/Religion/Hinduism` |
