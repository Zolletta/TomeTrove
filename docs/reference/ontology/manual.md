# Manual

Technical-operational text with instructions and procedures (how to do).

## Genre hierarchies

| Classification                                  | Description                                                                     | Examples                                                                                                                                                      |
|-------------------------------------------------|---------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `Manual/<Animal>`                               | Animal-related manuals (training, care, nutrition, behavior, breed)             | *Don't Shoot the Dog* (Karen Pryor), *The Complete Dog Book* (American Kennel Club)                                                                           |
| `Manual/<Art>`                                  | Art and craft technique manuals                                                 | *Drawing on the Right Side of the Brain* (Betty Edwards), *The Photographer's Eye* (Michael Freeman)                                                          |
| `Manual/Cooking/Recipe`                         | General recipe collections and cookbooks                                        | *The Joy of Cooking* (Irma S. Rombauer)                                                                                                                       |
| `Manual/Cooking/Recipe/<Cuisine>`               | Recipes scoped by cuisine                                                       | *Mastering the Art of French Cooking* (Julia Child) → `Manual/Cooking/Recipe/France`, *Veganomicon* (Isa Chandra Moskowitz) → `Manual/Cooking/Recipe/Vegan`   |
| `Manual/Cooking/Technique`                      | Culinary techniques and cooking methods                                         | *The Professional Chef* (Culinary Institute of America)                                                                                                       |
| `Manual/Cooking/Wine`                           | Wine guides, pairing manuals, tasting techniques                                | *The Wine Bible* (Karen MacNeil)                                                                                                                              |
| `Manual/Computer Science/Algorithm`             | Algorithm design and implementation                                             | *Introduction to Algorithms* (Thomas H. Cormen)                                                                                                               |
| `Manual/Computer Science/DevOps`                | DevOps practices and tools                                                      | *The Phoenix Project* (Gene Kim)                                                                                                                              |
| `Manual/Computer Science/<ProgrammingLanguage>` | Programming language manuals                                                    | *Eloquent JavaScript* (Marijn Haverbeke) → `Manual/Computer Science/JavaScript`, *The C Programming Language* (Brian Kernighan) → `Manual/Computer Science/C` |
| `Manual/Computer Science/Security`              | Cybersecurity practices and techniques                                          | *The Web Application Hacker's Handbook* (Dafydd Stuttard)                                                                                                     |
| `Manual/Computer Science/Software`              | Software usage and programming guides                                           | *Clean Code* (Robert C. Martin)                                                                                                                               |
| `Manual/Craft`                                  | Handicraft and DIY instructions                                                 | *The Complete Book of Woodworking* (Tom Carpenter)                                                                                                            |
| `Manual/Dance`                                  | Dance and choreography manuals                                                  | *The Intimate Act of Choreography* (Lynne Anne Blom)                                                                                                          |
| `Manual/Gardening`                              | Gardening and horticulture instructions                                         | *The Well-Tended Perennial Garden* (Tracy DiSabato-Aust)                                                                                                      |
| `Manual/Health`                                 | Health and fitness guides                                                       | *Starting Strength* (Mark Rippetoe)                                                                                                                           |
| `Manual/<Instrument>`                           | Instrument playing manuals                                                      | *The Piano Handbook* (Carl Humphries)                                                                                                                         |
| `Manual/<Language>`                             | Language learning manuals (grammar, vocabulary, conversation, exam preparation) | *English Grammar in Use* (Raymond Murphy), *Pimsleur Italian* (Pimsleur)                                                                                      |
| `Manual/<Sport>`                                | Technique and training manuals for a specific sport                             | *Total Soccer* (Phil Woosnam)                                                                                                                                 |
