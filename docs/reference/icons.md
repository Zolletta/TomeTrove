# Icon reference

TomeTrove uses a curated subset of [Phosphor Icons](https://phosphoricons.com/) (regular weight). Icons are bundled in a single file as an Alpine.js `<x-icon>` component — see [ADR 0007](../explanation/adr/0007-frontend-delivery.md) for the rationale.

This page lists every icon in the set, its Phosphor name, its Figma variable name, and where it is used.

## Usage in HTML

```html
<x-icon name="magnifying-glass" class="w-5 h-5 text-secondary"></x-icon>
<x-icon name="bell" class="w-5 h-5 text-primary"></x-icon>
```

The component renders an inline `<svg>` with `currentColor` for stroke/fill. Tailwind text-color classes (`text-primary`, `text-secondary`, `text-accent`, etc.) control the icon color. Size is controlled by `w-*` and `h-*` Tailwind classes.
